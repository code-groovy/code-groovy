# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues.

Use GitHub's [private vulnerability reporting](https://github.com/code-groovy/code-groovy/security/advisories/new) instead. Include a description of the issue, the steps to reproduce it and the affected version.

You should receive a response within 7 days. Fixes are released as a new extension version, and the advisory is published once the fix is available.

## Supported versions

Only the latest version published on the Visual Studio Marketplace receives security fixes.
