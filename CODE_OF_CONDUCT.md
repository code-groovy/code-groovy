# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

We expect everyone who participates in issues, discussions and pull requests to be respectful, constructive and welcoming, regardless of experience level or background. Harassment, personal attacks and discriminatory language are not tolerated.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainers at **marlondiego407@gmail.com**. All reports are reviewed promptly and handled confidentially.

Maintainers may remove comments, commits, issues and other contributions that violate this code of conduct, and may temporarily or permanently ban contributors whose behavior is harmful to the community.
